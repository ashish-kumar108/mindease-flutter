# MindEase

A Flutter wellness application combining guided meditation, yoga sessions, journaling and personalized user profiles.

## Highlights

- Guided meditation audio sessions
- Yoga flows with session guidance
- Personal journal and daily wellness tracking
- Firebase Authentication and Google Sign-In
- Onboarding, profile and settings workflows
- Persistent preferences and responsive Flutter UI

## Tech stack

Flutter, Dart, Firebase Auth, Google Sign-In, Just Audio, SharedPreferences and Google Fonts.

## Run locally

```bash
flutter pub get
flutter run
```

Configure your own Firebase project before enabling authentication.

## Project status

Portfolio project focused on authentication, audio experiences, multi-screen navigation and polished mobile UI.
